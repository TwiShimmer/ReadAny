## 概述

ReadAny 是客户端阅读器，**不提供**云服务，也**不会**替你运行 WebDAV 服务端。跨设备同步依赖你已有的存储：

- **WebDAV** — Nextcloud、坚果云、Box，或 wsgidav 等自建服务
- **S3 兼容存储** — 在**设置 → 同步**中单独配置

所有设备必须连接同一服务器、同一账号和同一个**远程文件夹**。ReadAny 不会把两个不同的远程文件夹合并为一个书库。

## 连接前的检查清单

- [ ] **服务器地址**，包含 WebDAV 的路径前缀，例如 `https://dav.example.com/dav/`
- [ ] **用户名**和应用专用密码（推荐），不要直接使用主账号密码
- [ ] **远程文件夹** — 默认 `readany`，支持 `apps/readany` 这类嵌套路径；点击**测试连接**或首次同步时会自动创建
- [ ] 该文件夹的**写入权限**。ReadAny 需要列目录、建目录、上传、下载、移动和删除文件
- [ ] **足够空间**存放同步元数据、书籍文件和封面
- [ ] **最终路径确认** — 同步数据位于 `<服务器地址>/<远程文件夹>/sync/...`，书籍文件位于 `<服务器地址>/<远程文件夹>/data/books/...`

ReadAny 不会扫描或导入你手动放进远程文件夹的书籍。如需浏览已有远程书库，请使用**导入 → 连接其他 WebDAV**。

## 设置步骤

1. 打开**设置 → 同步**，选择 **WebDAV**
2. 填写服务器地址、用户名、密码或应用专用密码
3. 设置**远程文件夹**（默认 `readany`）
4. 点击**测试连接**。此操作会验证登录并创建同步目录。
5. 点击**保存配置**
6. 在每台设备上点击**立即同步**

除非你清楚风险，不要开启**允许不安全连接**。桌面端会跳过 TLS 证书校验；移动端会把连接地址从 `https://` 改写为 `http://`。该选项只应用于受信任局域网内的自签名证书或明文 HTTP。

## 远程目录结构

使用默认远程文件夹（`readany`）时，ReadAny 会写入：

```text
<远程文件夹>/
├── sync/
│   ├── index.json                    # 书库成员与每本书的变更标记
│   ├── books/<bookId>.json           # 书籍记录、高亮、笔记、书签
│   ├── threads/<threadId>.json       # 对话线程元数据
│   ├── chat/<YYYY-MM-DD>.json        # 当天创建的聊天消息
│   ├── profile/<table>.json          # 标签、分组、技能等
│   └── sessions/<YYYY-MM>.json       # 阅读会话，按月分片
└── data/
    ├── books/
    │   └── <清洗后的标题>-<bookId>/
    │       ├── <清洗后的标题>.<书籍扩展名>
    │       └── <清洗后的标题>.<封面扩展名>
    └── file-manifest.json            # 远程书籍文件的轻量索引
```

`index.json` 是共享的变更索引。`file-manifest.json` 用于避免每次完整扫描目录；如果它缺失或过期，ReadAny 会回退到扫描目录。

### 书籍目录命名

目录名由**展示标题 + 书籍 ID** 组成：

```text
三体-3f2a9c1e-8b7d-4c2a-9f10-1d2e3f4a5b6c
```

- 标题会被清洗：`/ \ : * ? " < > |`、控制字符和连续空白会被替换或移除，标题最长 64 个字符。
- 没有可用标题时使用占位名 `未命名`。
- 末尾的 UUID 是稳定的书籍 ID。即使展示标题变化，ReadAny 仍能通过它把目录匹配到书籍。
- 重命名书籍会改变目录名。下次同步时 ReadAny 会把文件移动到新目录，请不要手动重命名这些目录。

旧版本和局域网同步使用“每设备快照”结构：

```text
<远程文件夹>/sync/device-<deviceId>.json
<远程文件夹>/data/file/<bookId>.<ext>
<远程文件夹>/data/cover/<bookId>.<ext>
```

当前云端同步会读取这些文件做迁移，并把书籍文件移动到按书目录中。升级后或仍在使用局域网同步时，你可能还会看到它们。迁移期间不要手动删除。

## 同步内容

- 阅读进度与当前位置
- 高亮、笔记和书签
- 书籍元数据、标签、分组和阅读会话
- 对话线程与消息
- 书籍文件和封面

书籍文件**会**按书同步。元数据与书籍文件属于两个阶段，因此元数据同步成功不代表所有书籍文件都已传输完成。

## 新设备与批量下载

普通同步**不会**批量下载远端书籍文件。ReadAny 会先拉取元数据，因此远端书籍会以“远端/待下载”状态出现在书架，但 `downloadRemoteBooks` 默认为 `false`。

- **打开一本远端书籍**时，才会按需下载该书文件。
- 如需一次下载全部内容，使用**设置 → 同步 → 高级 → 完全下载**。该操作会覆盖本机数据库并重新下载远端书籍和封面，请谨慎使用。
- 普通同步仍会上传本机存在、远端缺失的书籍文件。

## 文件失败时的含义

同步结果会分别报告元数据和文件传输：

- 元数据已应用、但部分书籍或封面失败，也可能显示为同步完成。
- 同步详情会列出上传/下载成功和失败的文件数量。
- 单个文件失败不会中断整批任务；提示类似“部分文件未同步（N 个上传失败，M 个下载失败）”。
- 下一次同步会自动重试缺失文件。

如果同一文件持续失败，请检查服务器写入权限、剩余空间、路径长度、反向代理的请求体大小限制，以及文件是否异常大。之后重试。如果远端副本有误，请在有正确文件的那台设备上执行**完全上传**。

## 已知限制

以下限制适用于当前 1.3.x 版本。相关修复在跟踪中，但本页不承诺具体发布时间。

- **超大书籍可能失败。** 已知部分环境会在 200 MB 以上的书籍文件上失败。桌面端上传路径会先把文件读入内存再 PUT，书籍文件传输超时为 300 秒。请尽量让单本书保持在 200 MB 以下；超大 PDF 或漫画压缩包建议拆分。
- **旧版 WebView2 可能无法渲染 PDF。** Windows 用户请通过 Windows Update 或官方安装程序更新 Microsoft Edge WebView2 Runtime。
- **弱服务端不适合并发突发。** 部分 NAS 和消费级 WebDAV 网关在并发时会限流或返回 401/429。可在同步设置中把**并发传输数**降到 1–2。
- **服务端保存的是明文文件。** ReadAny 不提供端到端加密。你的 WebDAV 服务商可以读取同步 JSON 和书籍文件，请选择可信的服务商。**允许不安全连接**会进一步削弱安全性：桌面端跳过 TLS 校验，移动端可能把 `https://` 降级为 `http://`。
- **部分服务器不接受过长或特殊路径。** 目录名包含 36 个字符的书籍 ID。如果服务器路径长度限制较严，请让远程文件夹保持较浅的层级。

平台与运行时要求见[系统要求与已知限制](/ReadAny/zh/support/requirements/)。

## 使用 wsgidav 自建 WebDAV

[wsgidav](https://github.com/mar10/wsgidav) 是一个轻量的 Python WebDAV 服务端，适合个人 ReadAny 书库。以下是最小部署步骤；在把服务暴露到 localhost 之外前，请先阅读 [wsgidav 官方文档](https://wsgidav.readthedocs.io/en/latest/)。

```bash
# 安装服务端及推荐的 WSGI 服务器
python -m pip install wsgidav cheroot

# 创建数据目录
mkdir -p /srv/readany-dav

# 只绑定回环地址，不要直接暴露此端口
wsgidav --host=127.0.0.1 --port=8090 --root=/srv/readany-dav
```

默认配置允许匿名访问。请保持只监听 `127.0.0.1`，并在前面加上身份认证与 HTTPS；或者按 wsgidav 文档配置其自带认证。

最小 nginx 反向代理示例：

```nginx
server {
    listen 443 ssl;
    server_name dav.example.com;

    ssl_certificate     /etc/ssl/fullchain.pem;
    ssl_certificate_key /etc/ssl/privkey.pem;

    # ReadAny 会上传整本书，代理不要限制请求体大小
    client_max_body_size 0;

    location /dav/ {
        proxy_pass http://127.0.0.1:8090/;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;

        # 让上传流式转发，避免代理落盘缓冲
        proxy_request_buffering off;
        proxy_read_timeout 300s;
    }
}
```

然后在 ReadAny 中填写：

- **服务器地址**：`https://dav.example.com/dav/`
- **远程文件夹**：`readany`
- **用户名 / 密码**：由反向代理或 wsgidav 强制的凭据

反向代理必须放行 `PROPFIND`、`MKCOL`、`PUT`、`GET`、`MOVE`、`DELETE` 等 WebDAV 方法。nginx 默认会放行，但部分 WAF 和 CDN 会拦截非 GET/HEAD 请求。

## 故障排查

| 现象 | 检查项 |
|---|---|
| `401` / 认证失败 | 用户名和应用专用密码；部分服务商要求使用应用密码而非账号密码 |
| `403` / 无权限 | 文件夹权限；账号必须能在远程文件夹中创建和删除文件 |
| `404` / 未找到 | 服务器地址路径、远程文件夹拼写、WebDAV 端点是否启用 |
| `405` / 方法不允许 | 服务器未开启 WebDAV，或代理/WAF 拦截了 `PROPFIND`、`MKCOL`、`MOVE` |
| 超时 | 网络连通性、端口、代理超时，以及书籍文件传输 300 秒的限制 |
| TLS 证书错误 | 证书链与主机名；使用受信任证书。仅在受信任局域网使用**允许不安全连接** |

## 冲突处理

同一本书在多台设备上发生修改时，ReadAny 以行级时间戳做最近写入合并，删除通过墓碑传播。高亮、笔记和消息按条目合并，尽可能保留两台设备上的修改。
