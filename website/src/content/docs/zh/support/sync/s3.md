## 概述

ReadAny 可以使用 S3 兼容存储桶替代 WebDAV。支持的服务类型包括 AWS S3、Cloudflare R2、MinIO、阿里云 OSS 和腾讯云 COS，其他实现 S3 API 的服务也可以使用。

ReadAny 是客户端阅读器：存储桶、凭据和网络访问都由你提供。存储桶不是 ReadAny 的服务，ReadAny 不管理你的计费或数据保留策略。

## 设置步骤

1. 打开**设置 → 同步**，选择 **S3**
2. 填写**服务端点**、**区域**、**存储桶**和**同步目录**
3. 填写 **Access Key ID** 和 **Secret Access Key**
4. 如果服务商要求，开启**使用路径样式 URL**
5. 点击**测试连接**
6. 点击**保存配置**，然后点击**立即同步**

### 字段说明

| 字段 | 填写内容 |
|---|---|
| **服务端点** | S3 API 地址，必须包含 `https://`，例如 `https://s3.example.com` |
| **区域** | 服务商要求的区域。部分 S3 兼容服务接受 `auto`；AWS S3 需要 `us-east-1` 这类真实区域 |
| **存储桶** | 存储桶名称。请先在服务商控制台创建存储桶，ReadAny 默认它已存在 |
| **同步目录** | ReadAny 独占的 key 前缀，默认 `readany`；支持 `apps/readany` 这类多级前缀 |
| **Access Key ID** | 受限于该存储桶或前缀的访问密钥 |
| **Secret Access Key** | 与 Access Key ID 匹配的密钥，由 App 保存在本机 |
| **使用路径样式 URL** | 强制使用 `endpoint/bucket/key` 而非 `bucket.endpoint/key`。MinIO、localhost 和 IP 端点通常需要开启；AWS S3 和大多数基于域名的服务可使用虚拟主机样式 |

**测试连接**只检查 ReadAny 能否列出配置前缀下的对象，不验证写入、删除或复制权限。

## 存储桶权限

ReadAny 会使用以下操作：

- 列出同步目录下的对象
- 读取对象
- 写入对象
- 删除对象
- 复制对象，用于重命名书籍目录时的移动操作（复制后删除）

仅允许 `s3:ListBucket`、`s3:GetObject`、`s3:PutObject`、`s3:DeleteObject`（作用于该存储桶及其对象）即可完成普通同步。请在连接 ReadAny 前先在服务商控制台创建存储桶。

## 远端目录结构

S3 没有真正的目录，只有 key。ReadAny 在**同步目录**前缀下写入与 WebDAV 相同的逻辑结构：

```text
<同步目录>/
├── sync/
│   ├── index.json
│   ├── books/<bookId>.json
│   ├── threads/<threadId>.json
│   ├── chat/<YYYY-MM-DD>.json
│   ├── profile/<table>.json
│   └── sessions/<YYYY-MM>.json
└── data/
    ├── books/
    │   └── <清洗后的标题>-<bookId>/
    │       ├── <清洗后的标题>.<书籍扩展名>
    │       └── <清洗后的标题>.<封面扩展名>
    ├── file/                          # 仅旧版布局
    ├── cover/                         # 仅旧版布局
    └── file-manifest.json
```

目录布局、书籍目录命名、重命名迁移和旧布局都与 [WebDAV 同步](/ReadAny/zh/support/sync/webdav/) 相同。使用默认同步目录时，`/readany/data/books/...` 这类逻辑路径会变成 `readany/data/books/...` 这样的 key。

## 同步行为

- 元数据与书籍文件分两个阶段同步。
- 在 S3 上，普通同步不会批量下载远端书籍文件。打开远端书籍时才会下载，或使用**设置 → 同步 → 高级选项 → 全量下载**。
- 即使普通同步不下载书籍文件，缺失的封面也会自动补齐。
- 书籍文件上传失败会在下次同步重试；书籍文件下载失败需要再次打开该书，或执行全量下载。
- 局域网传输是独立通道，可通过局域网下载缺失的书籍和封面。

完整的失败语义与已知限制见 [WebDAV 同步](/ReadAny/zh/support/sync/webdav/)。200 MB 以上的大文件限制同样适用于 S3。

## 安全

- 使用 HTTPS 端点。明文 HTTP 会暴露凭据和书籍文件。
- 为 ReadAny 创建受限的访问密钥，不要使用账号级管理员密钥。
- 从 ReadAny 的角度看，S3 保存的仍是明文对象。ReadAny 不提供端到端加密，服务商可以读取同步 JSON 和书籍文件。
- 把密钥限制在 ReadAny 使用的存储桶和前缀内。

## 故障排查

| 现象 | 检查项 |
|---|---|
| `SignatureDoesNotMatch` | Secret Access Key、Access Key ID 和区域 |
| `NoSuchBucket` | 存储桶名称和区域；先在服务商控制台创建存储桶 |
| `AccessDenied` | 存储桶策略和密钥的列出/读取/写入/删除权限 |
| 连接错误或超时 | 服务端点、`https://`、DNS、防火墙和服务商状态 |
| 存储桶样式请求失败 | 开启**使用路径样式 URL**（MinIO、localhost 和 IP 端点常见） |
| 对象出现在意外位置 | **同步目录**前缀会加到每个 key 上；请使用专用前缀 |
